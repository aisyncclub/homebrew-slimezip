# SlimeZIP Homebrew tap

The cask for [**SlimeZIP**](https://github.com/aisyncclub/slimezip) — a macOS
menu bar organizer that tucks your status icons behind one slime.

```bash
brew install --cask aisyncclub/slimezip/slimezip
```

That one command taps this repository, installs the app, and marks the cask
trusted. There is no separate `brew tap` or `brew trust` step.

Then turn SlimeZIP on in **System Settings → Accessibility**. Without that
permission it cannot read which icon belongs to which app, so the list looks
empty.

## Why a tap and not homebrew-cask

The official repository has a notability rule — 75 stars, 30 forks or 30
watchers — and SlimeZIP has none of them yet. The rule keeps the core tap from
filling with abandoned software, which is fair. Once the project clears it,
the cask moves and the command gets shorter.

## What is in here

One file, [`Casks/slimezip.rb`](Casks/slimezip.rb), regenerated by
[`scripts/cask.sh`](https://github.com/aisyncclub/slimezip/blob/master/scripts/cask.sh)
on every release. The checksum comes from the DMG that actually shipped rather
than from someone typing it, which is how casks end up rejecting a legitimate
download months later.

The app and the disk image are both notarized by Apple, so the download opens
with Homebrew's quarantine flag intact. Homebrew dropped `--no-quarantine` in
4.7, so that is no longer optional.
